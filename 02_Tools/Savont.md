# Tool: Savont

- **Category:** #tool/ASV #tool/classifier

- **Primary Paper / Citation:** https://www.biorxiv.org/content/10.64898/2026.05.26.727271v1

## Overview
### Brief summary of tool
Savont is a tool that can be used to generate Amplicon Sequence Variants (ASV) at a single-nucleotide resolution from long-read amplicon sequencing data generated by the Oxford Nanopore technology. This can also be used for taxonomic classification (as will be done for this project)

Why use savont? The supplied repository gives an answer to this:
- It can resolve ASV's that differ by a single nucleotide, even for nanopore reads.
- For ONT amplicons , savont requires about 10x less depth to generate ASV's
- Most importantly (for our project) Savont has built-in support for taxonomic profiling for several rRNA databases. 
## Installation & Environment

### Building from source
#### Requirements
- Rust (v > 1.88)
- Linux toolchain
- cmake


```bash
git clone https://github.com/bluenote-1577/savont
cd savont

cargo install --path .
```

### Conda
```bash
conda install -c bioconda savont
```
