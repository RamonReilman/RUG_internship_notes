## Introduction
The department is currently working with a 16S and 18S built in pipeline for nanopore amplicon sequencing. This pipeline works, but is limited in customizing settings, so very rigid. Working with different or custom databases also does not work well with this pipeline. My task for the incoming 20 weeks is look to develop a new pipeline for analyzing universal 16S and 18S amplicon data generated by the Oxford Nanopore tech (ONT) sequencing.

There are multiple research questions that i am aiming to answer, these will be listed below:
- How can bacterial, archaeal, and eukaryotic amplicon sequences be classified consistently using a universal 16S/18S marker?
- Can existing 16S/18S reference databases be combined effectively, or does the workflow need to merge classifications from seperate databases.
- How do Amplicon Sequence Variant (ASV) based  ONT workflows compare to currently used read-by-read classification approaches
- What are the best practices for analyzing universal amplicon data from marine ecosystems

The main goal of the project will be to look into ASV based tools and workflows, and to create a new workflow that uses either a custom database, or merges the classification of multiple databases using an ASV based tool like [Savont](/02_Tools/Savont.md) (and possibly others if i find other interesting tools). The other questions (1, 2, and 4) should be answered along the way.
