The output for this gives us many interesting files. I'm seeing that the 4 replicates are all combined into 1 sample called `trimmed`. This is unwanted behavior, and so I will run nextflow again. This will be a bit different as I will do all replicates separately.

```bash
for rep in rep1 rep2 rep3 rep4; do
	nextflow run epi2me-labs/wf-16s \
	--fastq "/home/hackllab/for-ramon/gutmock_out/trimmed/${rep}.fastq" \
	--out_dir /home/ramon/output/${rep} \
	--sample "$rep" \
	--classifier minimap2 \
	-with-apptainer \
	-without-docker \
	--threads 4 
done
```
