#### CAMI / OPAL
CAMI was mentioned before, and even has it's own literature review (found [here](/03_Reviews/Literature%20Review%20-%20CAMI.md)). OPAL was not mentioned before during this project. These 2 methods are the core benchmarking statistics for metagenomics-related tools. CAMI (or Critical Assessment of Metagenomics Interpretation) gives a set of metrics, and ways to interpret the metagenomics tools . OPAL implements these metrics.
The following metrics are implemented by OPAL:
- L1
- UniFrac
- TP/FP/FN
- Precision
- Recall
- F1
- Jaccard
- Diversity metrics

OPAL takes at least 2 different input files:
1. A gold standard taxonomic profile
2. 1 or more predicted taxonomic profiles.
These inputs have to be in a specific input format. a "CAMI profiling format".

#### “Benchmarking bacterial taxonomic classification using nanopore metagenomics data of several mock communities.” - Van Uffelen, A., Posadas, A., Roosens, N.H.C. _et al._

This paper also gives insight into how to benchmark the metagenomic tools, in this case specifically for Genus and Species taxonomic ranks.
They explicitly calculated the following metrics:
- TP/FP/FN
- Precision
- Recall
- L1

They also define and use metrics that are not used within OPAL or CAMI, but can still be interesting to look more into.
##### L1 Distance
The L1 distance is a metric that can give information on what sample is actually the closest to what the ground truth is.

##### Recall Precision
The article calculates the Recall and precision multiple times, with a varied relative abundance threshold. This generates precision-recall cures. This can be used to calculate the area under the curve.
