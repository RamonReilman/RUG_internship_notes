### Savont first run
The first step is the generate the ASVs. More on the Savont tool and working can be found at [Literature Review - Savont (tool)](/03_Reviews/Literature%20Review%20-%20Savont%20(tool).md). The first command for this is relatively simple:
#### Run 2
```python

savont asv --pooled-samples \
/home/hackllab/for-ramon/gutmock_out/trimmed/rep1.fastq \

/home/hackllab/for-ramon/gutmock_out/trimmed/rep3.fastq \

-o /home/hackllab/for-ramon/savont_out \
-t 5
```
This command finished very fast, in about 14 seconds. The output for this command can be found below:
- final_asvs.fasta - The final ASV sequences.
- feature-table.csv - Feature table (row ID match `final_asv_N_depth_M` from fasta)
- final_assignments.tsv - Read-to-asv assignment table. One row per read, columns: `read_id`, `asv`, `alignment_identity`, `est_read_identity`.
- temp/ - Temporary files.

These can be used as an input for the classifier functionality. This functionality uses the generated ASVs and a reference database to generate a taxonomic profile, with abundance.

#### Run 3
