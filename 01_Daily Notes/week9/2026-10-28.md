Savont is split up into 2 steps:
- ASV

The ASV step clusters the raw reads into ASVs, this step is independent from a database. The classify step is then used to assign taxonomies to these existing ASVs, and this where the reference databases are used. So to keep the ASV clusters consistent between classifications, you'd have to run all classify steps on the same generated ASV clusters.

The tie-breaking system works like this:
"Here's how savont actually deals with tie breaks right now, which is a bit poorly documented and may be useful to know:

1. Each ASV gets mapped to the reference database. All unambiguously best hits are pooled together for each ASV.
2. We look at the best hits across all ASVs, and then prefer taxonomy that are seen commonly across all ASVs.

This is done for the following reason: suppose a genome has two 16S copies, with two corresponding ASVs. ASV 1 may map perfectly to two different species, whereas ASV 2 unambiguously maps to the correct species. In this case, we'll assign both ASVs to the correct species.

This has a corollary that if many references are called "g_....; unannotated", it'll prefer the unannotated, since it's seen a lot." - bluenote-1577.

The only thing i want to figure out is how the abundances for species are calculated. I will demonstrate how this works below following one single species.
In the `savont_classify_marine_1` directory (previously generated via running Savont) we see 3 files:

The first one is the interesting one, as it is the file used for the tie-breaking system.
A species found in the `species_abundance.tsv` is *Archaeopneustes hystrix*. This has a abundance of 0.26 (for barcode 15). 

First i am interested to see which ASVs could contribute to this species.
This can be done by looking into the `asv_mappings`, and since i have limited experience with awk-cli data processing, i will try to use that to find the things i need.
```bash
awk -F'\t' '$6 == "Archaeopneustes hystrix"' asv_mappings.tsv | cut -f1
```
This command finds all ASVs that are linked with the species.
This gives me these 2 ASVs:
- final_asv_0_depth_0-278
- final_asv_1_depth_0-169
I then want to find the counts belonging to these ASVs (for barcode 15). These counts can be found in the `ASV` directory

```bash
for asv in final_asv_0_depth_0-278 final_asv_1_depth_0-169; do
	echo -n "$asv: "
	awk -F'\t' -v a="$asv" '$2 == a' final_assignments.tsv | grep -c "barcode=barcode15"
done
```

This gives me the following counts, based on both ASVs:
- final_asv_0_depth_0-278: 306
- final_asv_1_depth_0-169: 141
Now i want the total amount of counts, not accounting the unassigned values:
```bash
awk -F'\t' '$2 != "unassigned"' final_assignments.tsv | grep -c "barcode=barcode15"
```
This command finds all rows within that file, that are *not* unassigned, and counts the amount of lines for barcode 15:
1692
Now if we: (306+141) / 1692 = 0.26. Meaning using these files we have the ability to generate the abundance for a species.
